# Ommetryx

**Better fit. Fewer returns.**

Shopify-App für deutsche Mode-Händler: Sie empfiehlt Kundinnen die passende Größe, indem sie selbst vermessene Kleidungsmaße mit den Körpermaßen der Kundin vergleicht. Regelbasiert, ohne Machine Learning.

## Was hier liegt

| Ordner/Datei | Inhalt |
|---|---|
| `CLAUDE.md` | Projektstand, feste Entscheidungen, Datenschutzregeln, Arbeitsweise |
| `docs/` | Fachliche Grundlagen: Empfehlungslogik v3, Konfiguration (Excel), Kundenprofil, Barrierefreiheit, Datenschutz |

Der App-Code folgt in den nächsten Etappen (Empfehlungsmodul, Shopify-App, Widget).

## Wichtig

- Keine echten Kundendaten und keine echten Zugangsdaten in dieses Repo.
- Geheimnisse gehören nur in `.env`, die Datei wird nie hochgeladen.
